# BE_DoAn4

Backend Node.js và TypeScript cho Đồ án 4.

## Cài đặt

```bash
npm install
```

Sao chép `.env.example` thành `.env`, sau đó chỉnh cấu hình nếu cần.

## Chạy development

```bash
npm run dev
```

Server mặc định chạy tại `http://localhost:3000`.

## API mẫu

- `GET /`: thông tin API.
- `GET /api/health`: kiểm tra trạng thái backend.

## Build và chạy production

```bash
npm run build
npm start
```
